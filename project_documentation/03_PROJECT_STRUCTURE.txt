Other observed folders
- .venv\ is the active Python 3.12.10 environment.
- venv\ is a second Python 3.14.4 environment whose recorded interpreter path is external to this checkout.
- __pycache__\ directories contain generated bytecode.
- datasets\calvin\calvin\ contains a vendored repository and data. It is not part of the Flask import flow.

Important file connections
1. app.py serves templates and accepts POST /process.
2. app.py calls src\instruction_parser.py, src\task_decomposer.py, src\action_generator.py, src\robot_controller.py, and src\failure_detector.py.
3. templates\index.html and templates\voice_camera.html submit JSON to /process and render the response.
4. templates\robot_3d.html reads a successful result from browser sessionStorage and animates confirmed table orders.
5. integrated_pipeline.py is a command-line pipeline and shares execute_delivery_orders with app.py for parsed multi-orders.
6. tests\ contains the three unittest modules used by the 18-test run.
7. Data preparation scripts create/transform CSV/JSON data; no training job is connected to the web request path.

Important file purposes
- config\robot_config.json: legacy robot action/object/target/retry settings; not currently consumed by app.py execution.
- templates\backend.txt and templates\fronted.txt: brief notes, not executable application templates.
- static\ assets: standalone CSS/JS; current dashboard uses inline styles and scripts.
- pipeline_result.json, execution_logs.json, and evaluation_results.json: existing snapshots/artifacts, not a relational database.

Missing items
No project-root README content, schema/migration files, SQL database, model weights, hardware driver, ROS package, Arduino/ESP32 firmware, OpenCV/CV model, or dependency lockfile was found.

Inspection limits
The application-owned files listed above and selected data formats were inspected. The thousands of files inside virtual environments and every file in the vendored CALVIN tree were not read line-by-line. This tree summarizes the vendored subtree rather than duplicating its full third-party source tree. No application Git history is available at the root; see 28_CHANGELOG.txt.

Commands
From the root: `.\.venv\Scripts\python.exe app.py` starts Flask; `.\.venv\Scripts\python.exe -m unittest discover -s tests -v` runs tests.
