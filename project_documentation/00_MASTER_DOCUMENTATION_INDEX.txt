AI RESTAURANT SERVICE ROBOT
MASTER DOCUMENTATION INDEX

Purpose
This folder documents the existing project from inspected source files, data files, and tests. It describes code as it exists and distinguishes automated evidence from demonstrations and missing integrations.

Evidence labels
IMPLEMENTED: present in source code.
TESTED: covered by an automated test or a stated browser/manual run.
PARTIAL: a UI, stub, or software-only behavior exists, but not the complete real-world feature.
UNVERIFIED: not established by inspected tests or a reproducible run.
NOT IMPLEMENTED: the inspected project has no implementation for the stated capability.

Paths are relative to the project root. The files are plain UTF-8 text; open them in VS Code, Notepad, or another text editor. Start with this index and follow the reading order.

Inspection boundary
Application-owned files and the main source/data directories were inventoried. Virtual-environment package contents and the full vendored CALVIN repository were not read file-by-file; their existence and selected top-level metadata were inspected. See 03_PROJECT_STRUCTURE.txt and 28_CHANGELOG.txt.
